# 更新必须手动安装并使用 TUF 验证

Runtime 可以定时检查和按用户设置预下载稳定更新，但产品与 Mihomo 更新都必须由本机操作员明确安装，不允许配置来源或后台流程自动重启网络。Runtime 产品、普通 Mihomo 核心目标、在线包和离线包使用同一套 TUF 元数据验证版本、过期时间、签名阈值、摘要和大小，并保留离线 Root 密钥以支持轮换；GitHub Attestation、OpenPGP、SHA-256 和未来的 OS 代码签名只作为补充。高级操作员仍可明确选择只按固定官方 GitHub Release 和上游摘要安装尚未进入 TUF 的核心，但该风险例外不能成为默认、自动检查或离线导入路径。单个长期 Ed25519 清单更容易实现，却不能充分处理密钥轮换、旧版本重放和仓库冻结，因此不采用。
