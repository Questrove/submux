# 控制台通过页面快照读取状态

管理页面通过面向控制台的读取模块一次取得同一 bbolt 只读事务中的持久化状态，再由该模块完成来源统计、生命周期、模板版本、当前规则目录和输出订阅状态的页面组合；它是控制台专用的读取边界，不抽象成通用 Store 接口。控制台启动以及每次写入成功后都重新读取完整控制台快照，原有的设置、来源、节点、生命周期事件、模板、模板版本、规则方案和输出订阅管理读取接口不再提供；规则方案引用的历史规则目录仍按版本单独读取，写入接口和公开输出订阅接口保持不变。缺少可选的缓存、产物或更新状态按空值返回，缺少被引用资源时保留原记录并明确报告关联异常，损坏的持久化 JSON 则使整个快照读取失败。
