# 缺陷记录

## BUG-20260720-05：内置配置包含用户专属域名和路由网段

- 状态：已修复（v0.3.1）
- 优先级：P1
- 发现日期：2026-07-20
- 影响版本：`v0.3.0`
- 影响范围：新数据库初始化、内置“常用规则”、Mihomo 桌面 TUN 模板、订阅编译

### 现象与原因

内置“常用规则”的自定义规则预置了开发测试时使用的域名，桌面 TUN 模板还包含特定本地网络的路由排除网段。新服务器首次启动后，这些用户专属内容会保存到默认规则方案和模板，并进入相关 Mihomo 编译结果。

### 修复与验收标准

1. 内置规则方案的自定义规则默认为空。
2. 默认方案只包含通用 MetaCubeX 规则目录选择和兜底处理方式。
3. 内置桌面 TUN 模板不预设 `route-exclude-address`，需要绕过的网段由管理员自行添加。
4. 用户创建或保存的自定义规则和模板不受影响。
5. 新数据库生成的 Mihomo 配置不得包含任何开发者专属域名或网段。
